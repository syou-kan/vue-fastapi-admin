# 普通用户使用手册

## 概述

本手册为普通用户提供详细的系统使用指南，包括登录、个人信息管理、订单操作等功能的使用方法。

## 快速开始

### 1. 系统访问

#### 访问地址
- **生产环境**：https://your-domain.com
- **演示环境**：http://47.111.145.81:3000

#### 登录信息
- **用户名**：您的用户名（由管理员分配）
- **密码**：您的密码（首次登录后建议修改）

### 2. 首次登录

1. 打开浏览器，访问系统地址
2. 输入用户名和密码
3. 点击「登录」按钮
4. 首次登录建议立即修改密码

## 主要功能

### 1. 仪表盘

#### 功能概述
仪表盘是您登录后的首页，显示个人相关的数据概览。

#### 主要内容
- **个人订单统计**：显示您的订单数量和状态
- **最近活动**：显示您最近的操作记录
- **快捷操作**：提供常用功能的快速入口

#### 使用方法
1. 登录后自动进入仪表盘
2. 查看各项统计数据
3. 点击快捷操作按钮进入相应功能

### 2. 个人信息管理

#### 查看个人信息
1. 点击右上角头像
2. 选择「个人中心」
3. 查看个人基本信息

#### 修改个人信息
1. 进入个人中心
2. 点击「编辑」按钮
3. 修改可编辑的字段：
   - 姓名
   - 邮箱
   - 电话
   - 头像
4. 点击「保存」确认修改

**注意**：以下字段不可修改
- 用户名
- 角色权限
- 账户状态

#### 修改密码
1. 进入个人中心
2. 点击「修改密码」
3. 输入当前密码
4. 输入新密码（至少8位，包含字母和数字）
5. 确认新密码
6. 点击「确认修改」

### 3. 订单管理

#### 查看订单列表
1. 点击左侧菜单「订单管理」
2. 查看您的所有订单
3. 使用搜索和筛选功能：
   - 按订单号搜索
   - 按状态筛选
   - 按时间范围筛选

#### 订单状态说明
- **待处理**：订单已创建，等待处理
- **处理中**：订单正在处理
- **已完成**：订单已完成
- **已取消**：订单已取消

#### 创建新订单
1. 在订单管理页面点击「新建订单」
2. 填写订单信息：
   - 订单标题（必填）
   - 订单描述
   - 订单金额
   - 其他相关信息
3. 点击「提交」创建订单

#### 查看订单详情
1. 在订单列表中点击订单号
2. 查看订单的详细信息
3. 查看订单状态变更历史

#### 修改订单
1. 在订单详情页点击「编辑」
2. 修改可编辑的字段
3. 点击「保存」确认修改

**注意**：
- 只能修改自己创建的订单
- 已完成或已取消的订单不能修改
- 某些字段可能因订单状态而不可编辑

### 4. 系统设置

#### 语言设置
1. 点击右上角语言切换按钮
2. 选择「中文」或「English」
3. 系统界面语言立即切换

#### 主题设置
1. 点击右上角主题切换按钮
2. 选择「浅色模式」或「深色模式」
3. 界面主题立即切换

#### 全屏模式
1. 点击右上角全屏按钮
2. 进入全屏显示模式
3. 再次点击退出全屏

## 数据安全

### 数据隔离机制
系统采用严格的数据隔离机制，确保您只能访问自己的数据：

1. **用户数据隔离**：只能查看和修改自己的用户信息
2. **订单数据隔离**：只能查看和操作自己的订单
3. **菜单权限隔离**：只能看到分配给您角色的菜单

### 安全建议

1. **密码安全**
   - 使用强密码（至少8位，包含大小写字母、数字）
   - 定期更换密码
   - 不要与他人共享密码

2. **账户安全**
   - 及时退出登录
   - 不要在公共设备上保存登录信息
   - 发现异常立即联系管理员

3. **数据安全**
   - 不要泄露个人信息
   - 谨慎处理敏感订单信息
   - 定期检查个人数据

## 常见操作

### 1. 忘记密码
1. 联系系统管理员
2. 提供用户名和身份验证信息
3. 管理员重置密码后及时修改

### 2. 账户被锁定
1. 检查是否多次输入错误密码
2. 等待锁定时间结束
3. 或联系管理员解锁

### 3. 无法访问某功能
1. 检查是否有相应权限
2. 刷新页面重试
3. 联系管理员确认权限配置

### 4. 数据显示异常
1. 刷新页面
2. 清除浏览器缓存
3. 检查网络连接
4. 联系技术支持

### 常见问题解答

#### Q: 为什么我看不到某些菜单？
A: 这是正常的权限控制，普通用户只能看到分配给您的菜单。如需访问其他功能，请联系管理员。

#### Q: 为什么我不能删除订单？
A: 出于数据安全考虑，普通用户不能删除订单。如需删除，请联系管理员处理。

#### Q: 如何查看其他用户的订单？
A: 普通用户只能查看自己的订单，这是系统的安全设计。如需查看其他订单，请联系相关管理员。

#### Q: 系统运行缓慢怎么办？
A: 可以尝试刷新页面、清除浏览器缓存，或检查网络连接。如问题持续，请联系技术支持。
