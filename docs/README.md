# Vue FastAPI Admin 文档中心

## 概述

欢迎使用 Vue FastAPI Admin 系统文档中心。本系统是一个基于 FastAPI + Vue3 + Naive UI 的现代化前后端分离开发平台，融合了 RBAC 权限管理、动态路由和 JWT 鉴权。

## 🎯 核心特性

### 权限管理
- **RBAC 权限模型**：基于角色的访问控制
- **数据隔离机制**：用户级别的数据安全隔离
- **API 权限控制**：精确到接口级别的权限验证
- **前端权限指令**：组件级别的权限控制

### 安全特性
- **JWT 身份验证**：安全的 Token 认证机制
- **多层安全验证**：API + 数据 + 前端三层防护
- **攻击防护**：XSS、CSRF、SQL注入防护
- **审计日志**：完整的操作记录和监控

### 技术架构
- **后端**：Python 3.11 + FastAPI + SQLAlchemy
- **前端**：Vue3 + Vite + Naive UI + Pinia
- **数据库**：SQLite（默认）/ PostgreSQL / MySQL
- **部署**：Docker + Nginx + SSL/TLS
